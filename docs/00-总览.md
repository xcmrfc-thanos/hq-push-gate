# hq-push-gate 智析平台 — 项目总览

> 版本：V2.3（设计收敛版；00~05 为 V2.1 冻结基线，09 为 V2.3 实施总表，03 含 V2.2 补充 ADR——演进沿 00→03→09 递进，冲突以 docs/07 为准）
> 定位：**高可用、高性能、高并发**的多市场行情预警推送平台
> 用途：**论文 / 技术能力体现**（非商业项目，数据源采用开源数据 + 可控模拟负载生成器，无行情版权依赖）
> 终端：PC Web + H5 移动端（双 To-C 入口）

## 1. 一句话描述

> 多源行情接入 → Kafka 流总线 → Flink 流式计算（K线/指标/百万规则匹配）→ 秒级预警事件 → WebSocket 集群推送 → PC/H5 双端实时触达；历史数据落 ClickHouse + Doris 支撑海量查询与 AI 筛选。

## 2. 系统简图

```
 行情源(东财实时+Baostock 回填+sim)    PC Web (React)      H5 (React)
        │                                │                  │
        ▼                           APISIX 网关集群 + LB / CDN
  行情接入网关 Go ──▶ Kafka ──▶ Flink 流计算      │
    (多源容灾/标准化)   tick_raw   │  ├规则匹配──alert──▶ notify(alert-inbox)
                      rule_bcast │  └K线/指标          │
                                │      │               ▼
                                │      ▼        quote-push(快照/扇出) ─▶ WS 推送网关集群 Go
                                │  ClickHouse ◀─独立入库任务   │
                                │      │                    │
                                │  Doris(外表/查询层)         │
                                │  Redis(热快照)  MySQL(业务) │
                                └──────────┴────────────────┘
```

## 3. 核心技术指标（论文目标）

| 维度 | 指标 | 目标值 |
|---|---|---|
| 吞吐 | tick 处理能力 | ≥ 10 万条/秒 持续 |
| 延迟 | 预警端到端（源→客户端收到） | P50 < 500ms，P99 < 2s |
| 并发 | WebSocket 长连接 | 架构目标 **100 万**（docs/07 §3 连接层目标，非当前实测线）；单机 smoke 已实测 300 连接收 13.4 万推送（docs/09:157）；benchmark-small 10 万 / benchmark-large 100 万为 U3 集群验收线 |
| 查询 | 行情/K线查询 | ≥ 1 万 QPS（缓存命中率 > 90%） |
| 数据 | 时序存储规模 | 百亿~千亿行（CK 分片 + S3 归档设计） |
| 可用性 | 整体 SLO | 99.9%，核心链路 MTTR < 5min |
| 扩展 | 水平扩展线性度 | Flink/WS网关/查询服务 扩容加速比 ≥ 0.7 |

## 5. 业务边界（2026-09-07 修订：商业化仅为设计与技术实现交付物）

- 只做：行情查看、指标计算、条件预警、智能分组、消息推送、（可选）AI 筛选
- 不做：实盘交易、买卖点推荐、资金托管
- 商业化（套餐/配额/开放平台/计费计量）仅做设计与技术实现，不实际运营收费
- 所有输出仅为数据展示与条件触达，不构成投资建议

## 6. 非商业定位带来的简化

| 商业方案要素 | 本项目处理 |
|---|---|
| 商业行情源授权 | 不采购；AKShare 做历史灌数 + 自研模拟 tick 发生器（可配置压力级别，兼作压测负载源，是论文可控实验的关键） |
| 公众号推送 / 付费 API / 计费配额 | notify-service 渠道适配器化设计，WS 推送为核心渠道，其余为可选插件 |
| 多租户 B 端 SDK | 降级为可选扩展；核心服务 PC/H5 两个 To-C 端 |
| 合规（证券咨询牌照） | 仅做数据展示与预警通知，AI 筛选输出附免责声明 |
